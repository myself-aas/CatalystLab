Weighted Aggregate Scoring Formula

CatalystLab computes an overall composite score (0–100) using a normalized weighted average of all ten evaluated dimensions. Each category is assigned a calibrated weight reflecting its architectural impact on user experience, security posture, and discoverability:

📐 Composite Health Formula
Overall Score = Σ (Dimension Score × Weight)
Grade Thresholds: A+ (95–100), A (90–94), B (80–89), C (70–79), D (60–69), F (<60).
⚡

1. Performance & Core Web Vitals

Weight: 15%

Evaluates First Contentful Paint (FCP), Largest Contentful Paint (LCP), Cumulative Layout Shift (CLS), Speed Index, and payload compression.

  • Standards Reference: Google Chrome Core Web Vitals (web.dev/vitals).
  • Key Criteria: LCP < 2.5s, CLS < 0.1, payload gzipping, responsive image optimization.
🛡️

2. Security & SecOps Headers

Weight: 15%

Checks HTTPS enforcement, TLS 1.3 protocol negotiation, Content Security Policy (CSP), HSTS headers, X-Frame-Options clickjacking protection, and mixed-content leakage.

  • Standards Reference: OWASP Secure Headers Project (owasp.org).
  • Key Criteria: Strict-Transport-Security with subdomains, X-Content-Type-Options: nosniff, frame-ancestors.
🔍

3. SEO & Semantic Architecture

Weight: 10%

Assesses crawler indexability, title tag length (30–60 chars), meta description presence (50–160 chars), single primary H1 heading hierarchy, canonical URL linkage, and structured Schema.org JSON-LD data.

📱

4. Mobile & Touch Usability

Weight: 10%

Validates viewport meta configurations (e.g. width=device-width, initial-scale=1.0), touch target dimensions (minimum 44x44px), media query breakpoints, and absence of horizontal overflow scroll.

♿

5. Accessibility (WCAG 2.1 AA)

Weight: 10%

Audits image alternative text attributes, form input label bindings (<label for="...">), sequential heading hierarchy (no skipped H1 → H3 levels), ARIA landmark structures (main, nav, header), and HTML document language declaration.

  • Standards Reference: W3C Web Content Accessibility Guidelines (w3.org/WAI).
🌱

6. Digital Ethics & Carbon Footprint

Weight: 10%

Estimates transfer-size carbon emissions (g CO2 per pageview based on the Sustainable Web Design model), identifies invasive third-party tracking scripts, and checks for ethical privacy markers.

📐

7. W3C HTML5 Web Standards

Weight: 10%

Verifies HTML5 DOCTYPE validity, checks for deprecated legacy tags (<font>, <center>), audits maximum DOM tree depth (< 32 levels), and assesses semantic tag density.

🤖

8. AI & LLM Readiness

Weight: 8%

Scans for modern AI crawler discovery protocols including llms.txt, Model Context Protocol (MCP) agent discovery schemas, structured Schema.org contextual graphs, and robots.txt AI agent indexing policies.

✨

9. UX & Ecosystem Modernity

Weight: 7%

Inspects PWA web app manifests (manifest.json), preconnect / dns-prefetch resource hints, modern favicon link suites, and responsive UI theme color integration.

🌐

10. Social Graph & Open Graph Metadata

Weight: 5%

Validates Open Graph protocol tags (og:title, og:image, og:description, og:type) and Twitter Card tags to ensure rich, click-worthy visual previews across Slack, Discord, LinkedIn, and social feeds.
