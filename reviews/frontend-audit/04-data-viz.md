## Cross-cutting patterns
1. **`.ds-card` stays white in dark, but only part of its ink is re-scoped** (3 Critical rows, about 60 call sites). `ds-muted` and `ds-eyebrow` are not re-inked, and the patch still paints `bg-background`, `bg-card`, `bg-surface` and their `hover:` substrings dark inside the card. Fix it once in patch.css:1504-1513: add `--app-muted-foreground`, `--p-text-strong`, and `.ds-card [class*="bg-background"|"bg-surface"|"bg-card"]` → white or #F1F4F7. Do this rather than editing about 8 components.
2. **Tailwind palette status hues (`-300/-400/-600`) used directly** (about 70 occurrences across 8 files). They are tuned for the old dark cockpit and fail in light (1.4–3.8:1). patch.css rescues them only in dark. Replace them with `text-success/warning/danger/info`, which are already theme-aware (index.css:292-294, 461-463).
3. **`white` / `bg-white` / `--color-cream` as the "danger" or "status" colour** (RiskSslGaugeChart ×7, SystemHealthWidget ×2, UserRateLimitAllocationCard ×1, the `bg-white/10` pills in 6 files). This is a leftover from a monochrome dark pass. The danger state is invisible in light, and the states cannot be told apart.
4. **Fabricated or default telemetry presented as measured** (UserDomainMonitoringRadar, SystemHealthWidget, FramerAdminCockpit, SiteMonitoringView, UserAnalyticsDashboard, AuditScoreMatrixRadar, DiagnosticConsoleCard: 7 files). Adopt a "Not measured" convention like the clean `charts/*` files, which do this correctly.
5. **Unvalidated `fetch().json()`** with no `res.ok` check (UserDomainMonitoringRadar:92, UserRateLimitAllocationCard:81, SystemHealthWidget:67) and an unvalidated `JSON.parse` (RiskSslGaugeChart:41). Add Zod schemas next to the API types.
6. **Async list handlers that use stale `posts` closures**, plus loading states that stay on forever when there is no user (5 files). Use functional updates and set `loading=false` on every early return.
7. The `charts/*` report widgets used by DomainReportArticlePage (6 of 9 files) are clean. Their `bg-surface` + `text-foreground` + `text-success/danger` pattern is the model to copy.
