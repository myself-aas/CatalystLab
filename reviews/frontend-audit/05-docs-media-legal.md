## Cross-cutting patterns
- **Dark-only Tailwind hues (`text-cyan-400`, `-emerald-400`, `-rose-400`, `*-950` surfaces) on light-default surfaces: 6 files** (CLISimulator, PipelineVisualizer, WebhookFanoutMesh, ScanRevealFigure, AvatarStack, CodeBlock). patch.css repairs them only in dark, and it does so by flattening every hue to #F0FAFF, so status colour is lost there too. Fix it centrally with `text-success/-warning/-danger` and an accent token. A lint rule against `-[34]00` hue text outside invariant dark wells would stop new cases.
- **Inverted islands or white cards that hold their own nested surfaces: 2 files** (WebhookFanoutMesh `bg-primary` island with `bg-card` children; LegalDocumentView `.ds-card` with unclassed text and `text-warning`). The patch.css F2 rules recolour only classed descendants, and only some token families. Either extend F2 to set `color` on the container and cover `text-warning/success/danger`, or ban `bg-card`/`bg-muted` inside `bg-primary` islands.
- **Invariant dark chrome with flipping ink: 3 places** (react-dev TopNav and Layout header buttons; CodeBlock header and line numbers via `--react-text-secondary` / `text-muted-foreground`). The react-dev token sheet defines code surfaces as invariant but their ink as flipping.
- **patch.css substring collisions: 2** (DocsLayout `hover:bg-[var(--bg-surface)]` always applied in dark; `bg-surface dark:bg-background` dead variant). Any arbitrary value that contains `--bg-surface` or `--bg-background` will hit this. Grep `bg-\[var\(--bg-` repo-wide.
- **Theme state outside ThemeContext: 1** (react-dev Layout). This is the only place in the slice that writes `html.dark` directly. Route it through `useTheme()`.
- **Fake or simulated actions presented as real: 3** (security report submit, placeholder PGP key, "Confirm Merge" with no handler). The security ones are trust and safety issues, not only UX.
- **Unmanaged `setTimeout` in event handlers: 5** (CLISimulator, PipelineVisualizer ×2, WebhookFanoutMesh, SecurityDisclosureSection). None are cleared on unmount, and CLISimulator also closes over stale state.
- **Unassociated `<label>`s or div-as-button selection without state: 3** (SecurityDisclosureSection, WebhookFanoutMesh, CLISimulator log `role=button`).
- **Dead code: 4 unused media components plus the barrel**, and unused lucide/motion imports in 5 files (`noUnusedLocals` is off in tsconfig, so nothing flags them).
