# Glossary

_The product's canonical language. Pure vocabulary — no implementation._

**Assay** — One diagnostic run of one Engine against one Domain.
**Audit** — A complete set of Assays run together against one Domain, producing one Report.
**Domain** — The website under examination, named by the person requesting the Audit.
**Engine** — One of the eight named diagnostic specialists (VitalZyme, RiskProtease, LLMKinase, EdgeVmax, EcoHolo, SynthShift, GitLygase, Alloster) that performs a kind of Assay.
**Finding** — A single observed fact inside an Assay's result, with a Severity.
**Severity** — How much a Finding matters: passing, caution, or risk. Never decorative.
**Report** — The durable, shareable record of one Audit and all its Findings.
**Quota** — The number of Audits an account may run in a period.
**Operator** — The person running and reading Audits (any audience: team engineer, agency, solo developer).
